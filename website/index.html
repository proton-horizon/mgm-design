MGM Design / Guide

Your designs, all in one place.

MGM Design hosts your app's browser-ready designs. Each site has its own projects, people, and private mock files. A project contains boards; each board displays one or more screens.

Start here

Open your installation and sign in with the email and password your site admin shared. For a new installation, its owner creates the first admin with the setup key configured during deployment.
