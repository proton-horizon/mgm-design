Open a project in the left sidebar, then choose a board such as App or Clothing. On a phone, open Projects from the menu in the top-left corner. Search narrows the project list.

Pan mode

Drag the canvas or use two-finger scrolling to move around. Pinch to zoom. On desktop, hold Command or Control while scrolling to zoom around the pointer. The bottom controls zoom, restore actual size, and fit all screens. The small overview map recenters the canvas.

Key Action while the canvas has focus
F or 0 Fit all screens
1 Actual size
+ / − Zoom
Arrow keys Pan
Command / Control + K Find a project

Interact mode

Select a screen or choose it from Jump to screen, then press Interact. The focused screen accepts clicks and touch gestures. Use previous/next to switch screens and Back to canvas to continue exploring. A screen may restart when you open it or return to it.

How it works

Each screen is a separate HTML document displayed at the size declared by its app repository. The canvas moves and scales those documents together. Pan mode captures gestures; Interact mode passes input to the selected document. The sandbox prevents mock code from accessing your account or administration APIs.

Refresh designs loads the site's latest successful publication. An unsuccessful newer publication leaves the existing designs visible. Use the publication status at the top for details.
